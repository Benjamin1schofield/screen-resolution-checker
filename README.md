# Screen Resolution Checker

A browser utility for viewing display information.

## Features

- Screen dimensions
- Viewport size
- Device pixel ratio
- Color depth

## How to Use

Open the application to inspect your display information.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Compare screen width and height with device settings.
- [ ] Resize the window and check the viewport values.
- [ ] Review the displayed device pixel ratio.

Record the observed result and any reproducible issue after running the tests.
